# NetGuard — Threat Identification in Computer Networks

A cybersecurity educational website covering network threats, detection techniques, and an interactive quiz.

## 🌐 Live Website
Deployed via GitHub Pages.

## 📁 Files
- `index.html` — The complete website (HTML + CSS + JS in one file)

## 🚀 How to Deploy on GitHub Pages
1. Upload both files to a new GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save** — your site will be live in a few minutes!
